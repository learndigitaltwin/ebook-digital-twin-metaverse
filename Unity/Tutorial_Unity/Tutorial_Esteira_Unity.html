1O que você vai construir

Um gêmeo digital é uma réplica virtual de um sistema real que reflete, em tempo real, o que acontece com ele. Aqui você vai montar a parte virtual de uma esteira de pintura: caixas entram, passam por sensores e por três cabeçotes que aplicam base, acabamento e verniz, e seguem para a expedição. Cada acontecimento vira um evento enviado a um dashboard web.

UnityEsteira, sensores e cabeçotes (você vai montar)
➜
Dashboard (FastAPI)Recebe os eventos por HTTP
➜
NavegadorMostra a esteira e o histórico ao vivo

A esteira tem 4 sensores e 3 cabeçotes, nesta ordem:

PontoSensorCabeçoteAplicação
EntradaSensor_1—Entrada do processo
Ponto ASensor_2Cabecote_1Pintura de base
Ponto BSensor_3Cabecote_2Tinta de acabamento
Ponto CSensor_4Cabecote_3Verniz protetor
Como este tutorial funciona Você vai criar um projeto Unity vazio e trazer para dentro dele os materiais da pasta Tutorial_Unity/ (modelos, texturas e scripts). Os scripts vêm com 90% do código pronto — sobram 6 pequenos trechos marcados como PRA FAZER para você completar. A cada trecho, a simulação ganha vida.

2Pré-requisitos

  • Git com Git LFS (os modelos 3D e texturas ficam no LFS).
  • Unity Hub + Unity 6000.3.X (Ex.: 6000.3.23f1, ou versão compatível da linha Unity 6).
  • Python 3.10+ — só para rodar o dashboard.

3Passo 1 Clonar o repositório

Abra um terminal e rode os comandos abaixo. O git lfs install só precisa ser feito uma vez por máquina.

cd gemeo-digital-esteira

Depois de clonar, você terá estas pastas:

4Passo 2 Criar um projeto Unity limpo

  1. Abra o Unity Hub e clique em New project.
  2. Escolha o template Universal 3D (URP). Se aparecer só "3D (URP)", é o mesmo.
  3. Confirme a versão do editor.
  4. Dê um nome, por exemplo EsteiraGD, escolha a pasta e clique em Create project.
Precisa ser URP Os materiais usam o shader Universal Render Pipeline/Lit. Se o projeto for criado no template "3D" comum (Built-in), os materiais podem aparecer rosa. Use o template Universal 3D / URP.

5Passo 3 Organizar as pastas do projeto

No painel Project (parte de baixo), dentro de Assets, crie 5 pastas. Clique com o botão direito em Assets → Create → Folder e crie, uma a uma:

  • Scripts
  • Models
  • Textures
  • Materials
  • Prefabs

(A pasta Scenes já existe, criada pelo Unity.) Manter os arquivos organizados por tipo facilita achar tudo depois.

6Passo 4 Importar scripts, modelos e texturas

Importar no Unity é simples: arraste os arquivos do Explorador de Arquivos do Windows para dentro da pasta certa no painel Project.

6.1 — Scripts

Material fornecido — scripts C# Arraste os 6 arquivos de Tutorial_Unity/ScriptsParaCompletar/ para a pasta Assets/Scripts: Esteira.cs, GeradorDeCaixas.cs, SensorDaEsteira.cs, CabecoteDePintura.cs, GerenciadorDeSensores.cs e ClienteDashboardWeb.cs.

O Unity vai compilar os scripts. Como eles já foram feitos para compilar mesmo com os PRA FAZER em branco, não deve aparecer nenhum erro vermelho no Console.

6.2 — Modelos 3D

Material fornecido — modelos Arraste esteira.fbx e caixa.fbx de Tutorial_Unity/Modelos3D/ para Assets/Models. (O esteira.blend é opcional, para quem quiser editar o modelo no Blender.)

6.3 — Texturas

Material fornecido — texturas da caixa Arraste as 4 imagens de Tutorial_Unity/TexturasCaixa/ para Assets/Textures: 0_caixa_inicial_textura.png, 1_caixa_pintura_de_base_textura.png, 2_caixa_tinta_de_acabamento_textura.png e 3_caixa_verniz_protetor_textura.png.

  4. Ao lado de Base Map, clique no pequeno círculo (ou arraste a textura) e escolha a textura correspondente.

8Passo 6 Montar a esteira na cena

  1. No painel Project, abra Assets/Models e arraste o esteira para a janela Hierarchy (ou para a janela Scene).
  2. Com o objeto esteira selecionado, no Inspector, zere a posição do Transform: Position (0, 0, 0).
  3. Na Hierarchy, clique na setinha ▸ ao lado de esteira para expandir e ver as partes internas.

Você vai ver, entre outros, estes objetos-filhos (já vêm nomeados no modelo):

ObjetoO que é
Esteira_RoletesA superfície (rolos) por onde as caixas deslizam.
Esteira_Estrutura / Esteira_PernasEstrutura e pernas da esteira.
Sensor_1 … Sensor_4Os 4 sensores (barras vermelhas na lateral).
Cabecote_1 … Cabecote_3Os 3 aplicadores de tinta, no pórtico acima da esteira.
ChaoO piso da cena.
Não renomeie os objetos Os scripts descobrem o número de cada sensor/cabeçote pelo nome (Sensor_2 → sensor 2). Mantenha os nomes exatamente como estão.

9Passo 7 · PRA FAZER 1 Mover a esteira

Agora vamos fazer a superfície empurrar as caixas.

  1. Na Hierarchy, selecione Esteira_Roletes (a superfície da esteira).
  2. No Inspector, clique em Add Component e adicione um Box Collider. O Unity ajusta o tamanho dele automaticamente ao formato do objeto — ele deve cobrir o topo da esteira. Deixe Is Trigger DESMARCADO (as caixas precisam colidir, não atravessar).
  3. Ainda em Add Component, adicione o script Esteira.
  4. No componente Esteira, configure os valores abaixo.
Valores do componente Esteira:
Direcao = (-1, 0, 0)  ·  Velocidade = 1  ·  Travar Rotacao Z = marcado

O script empurra a caixa definindo a velocidade do Rigidbody dela, preservando o eixo Y (a gravidade). Falta você escrever essa linha.

PRA FAZER 1 — aplique a velocidade (arquivo Esteira.cs) No método AplicarMovimentoDaEsteira, escreva a linha que define a velocidade da caixa nos eixos X e Z, mantendo o Y atual. Para abrir o script, dê duplo clique nele no painel Project. 
Esteira.cs — escreva dentro do PRA FAZER 1corpoDaCaixa.linearVelocity = new Vector3(
    velocidadeDaEsteira.x,   // empurra no X
    velocidadeAtual.y,       // mantém a gravidade
    velocidadeDaEsteira.z    // empurra no Z
);

Salve com Ctrl+S e volte ao Unity (ele recompila sozinho).

10Passo 8 Criar o prefab da caixa

A caixa que percorre a esteira será um prefab (um objeto reutilizável que o gerador vai copiar).

  1. Arraste o modelo caixa de Assets/Models para a Hierarchy.
  2. Com a caixa selecionada, em Add Component adicione um Rigidbody (deixe Use Gravity marcado, massa 1).
  3. Adicione também um Box Collider (o Unity ajusta ao tamanho da caixa).
  4. No Mesh Renderer da caixa, no campo Materials → Element 0, coloque o material 0_caixa_inicial_material (a caixa "crua").
  5. Arraste a caixa da Hierarchy para a pasta Assets/Prefabs. Isso cria o prefab.
  6. Agora apague a caixa da Hierarchy (ela vai nascer pelo gerador; não precisa ficar solta na cena).
Por que Rigidbody e Box Collider? O Rigidbody faz a caixa obedecer à gravidade e ser empurrada pela esteira. O Box Collider dá "corpo" físico à caixa, para ela encostar na esteira e nos sensores.

11Passo 9 · PRA FAZER 2 Produzir caixas

  1. Na Hierarchy, clique com o botão direito → Create Empty. Renomeie o objeto para GeradorDeCaixas.
  2. No Inspector, ajuste o Transform → Position para (5.4, 1.5, 0) — logo acima da entrada da esteira.
  3. Em Add Component, adicione o script GeradorDeCaixas.
  4. No campo Caixa Prefab, arraste o prefab caixa da pasta Assets/Prefabs.
  5. Configure os valores abaixo.
Valores do GeradorDeCaixas:
Caixa Prefab = caixa  ·  Caixas Por Minuto = 20  ·  Spawn Ativo = marcado  ·  Destruir Depois De Segundos = 18

Falta o gerador saber de quanto em quanto tempo criar uma caixa.

PRA FAZER 2 — calcule o intervalo (arquivo GeradorDeCaixas.cs) No método CalcularIntervaloEntreCaixas, troque o return 60f; provisório pela conta correta. 
GeradorDeCaixas.cs — substitua o return provisórioreturn 60f / caixasPorMinuto;   // 60 segundos ÷ caixas por minuto

Dê Play (▶). As caixas devem nascer e deslizar pela esteira (PRA FAZER 1 + 2 funcionando juntos). Clique em Play de novo para parar.

12Passo 10 Gerenciador e Cliente do dashboard

Vamos criar dois objetos vazios que cuidam da lógica de dados. Eles não têm forma na cena.

  1. Crie um Create Empty, renomeie para GerenciadorDeSensores e adicione o script GerenciadorDeSensores.
  2. Crie outro Create Empty, renomeie para ClienteDashboardWeb e adicione o script ClienteDashboardWeb.
Componente ClienteDashboardWeb:
Url Do Servidor = http://localhost:8000/api/eventos  ·  Nome Da Fonte = Unity

Agora ligue o gerenciador ao cliente: selecione GerenciadorDeSensores e, no campo Cliente Dashboard, arraste o objeto ClienteDashboardWeb da Hierarchy.

13Passo 11 · PRA FAZER 3 Configurar os sensores

Faça o seguinte para cada um dos objetos Sensor_1, Sensor_2, Sensor_3 e Sensor_4 (são filhos da esteira):

  1. Selecione o sensor na Hierarchy.
  2. Em Add Component, adicione o script Sensor Da Esteira. Ele já exige um Box Collider, que o Unity adiciona e ajusta automaticamente ao formato do sensor. (O próprio script marca o collider como Trigger ao rodar.)
  3. No campo Gerenciador, arraste o objeto GerenciadorDeSensores da Hierarchy.
Dica para repetir rápido Depois de configurar o Sensor_1, você pode selecionar os quatro sensores juntos (segurando Ctrl) e arrastar o GerenciadorDeSensores para o campo de todos de uma vez. Mas o Add Component precisa ser feito em cada um.

Falta o sensor avisar o gerenciador quando "vê" uma caixa.

PRA FAZER 3 — avise o gerenciador (arquivo SensorDaEsteira.cs) Dentro do OnTriggerEnter, chame o método que registra a passagem. 
SensorDaEsteira.cs — escreva dentro do PRA FAZER 3gerenciador.RegistrarPassagem(numeroDoSensor, caixa);

Dê Play e abra o Console (Window → General → Console). A cada caixa que passa por um sensor, aparece uma mensagem como "Caixa 1 passou pelo Sensor_2 …".

14Passo 12 · PRA FAZER 4 Configurar os cabeçotes

Faça o seguinte para cada Cabecote_1, Cabecote_2 e Cabecote_3:

  1. Selecione o cabeçote na Hierarchy.
  2. Em Add Component, adicione o script Cabecote De Pintura (ele adiciona e ajusta o Box Collider automaticamente).
  3. No campo Material Da Pintura, coloque o material do estágio (tabela abaixo).
  4. No campo Cliente Dashboard, arraste o objeto ClienteDashboardWeb.
CabeçoteMaterial Da Pintura
Cabecote_11_caixa_pintura_de_base_material
Cabecote_22_caixa_tinta_de_acabamento_material
Cabecote_33_caixa_verniz_protetor_material
PRA FAZER 4 — pinte a caixa (arquivo CabecoteDePintura.cs) No OnTriggerEnter, troque o material do renderizador da caixa pelo materialDaPintura. 
CabecoteDePintura.cs — escreva dentro do PRA FAZER 4renderizadorDaCaixa.material = materialDaPintura;

Dê Play. Ao passar por cada cabeçote, a caixa muda de cor: base no Ponto A, acabamento no Ponto B e verniz no Ponto C.

15Passo 13 · PRA FAZER 5 e 6 Conectar ao dashboard

15.1 — Ligue o dashboard

Na pasta DashboardWeb_Python/, dê dois cliques em start_dashboard.bat. O navegador abre em http://localhost:8000. (Detalhes no README.md do repositório.) Deixe-o aberto.

Material fornecido — dashboard reutilizável O mesmo dashboard servirá para os próximos tutoriais. Por isso ele aceita eventos de qualquer fonte — você não precisa alterá-lo.

15.2 — PRA FAZER 5: identifique a fonte

Arquivo ClienteDashboardWeb.cs. Guarde o valor de nomeDaFonte (padrão "Unity") dentro do evento, para o dashboard mostrar de onde vieram os dados.

PRA FAZER 5
ClienteDashboardWeb.cs — escreva dentro do PRA FAZER 5evento.fonte = nomeDaFonte;

15.3 — PRA FAZER 6: envie o evento do sensor

Arquivo GerenciadorDeSensores.cs. Falta enviar os eventos dos sensores ao dashboard (os cabeçotes já enviam os deles).

PRA FAZER 6
GerenciadorDeSensores.cs — escreva dentro do PRA FAZER 6clienteDashboard.EnviarEvento("sensor", sensor, caixa, etapa, ultimoEvento);
Confira as referências antes de rodar Para os eventos saírem do Unity, o campo Cliente Dashboard precisa estar preenchido no GerenciadorDeSensores (Passo 10) e em cada Cabecote_N (Passo 12).

Com o dashboard aberto, dê Play. As caixas devem aparecer entrando na esteira do dashboard, os sensores (vermelho) e cabeçotes (amarelo) piscando, e o histórico enchendo ao vivo. No topo, Fonte dos Dados deve mostrar Unity.

16Passo 14 Câmera e teste final

Para ver a esteira de um bom ângulo, selecione a Main Camera e ajuste o Transform:

Main Camera: Position = (0, 5, 6)  ·  Rotation = (35, 180, 0)

Dica: com a câmera selecionada, use GameObject → Align View to Selected, ou posicione a visão na janela Scene e use GameObject → Align With View.

Salve a cena com Ctrl+S (ela fica em Assets/Scenes).

17Checklist e solução de problemas

  • As caixas nascem e deslizam pela esteira (PRA FAZER 1 e 2).
  • Os sensores registram as passagens no Console (PRA FAZER 3).
  • As caixas mudam de cor a cada cabeçote (PRA FAZER 4).
  • O dashboard mostra os eventos ao vivo e a fonte "Unity" (PRA FAZER 5 e 6).
  • Nenhum erro vermelho no Console.
SintomaCausa provávelSolução
Materiais aparecem rosaProjeto não é URPCrie o projeto com o template Universal 3D (URP).
Modelos/texturas faltandoGit LFS não baixou os bináriosRode git lfs install e git lfs pull.
A caixa não se movePRA FAZER 1 em branco, ou caixa sem Rigidbody, ou esteira sem Box Collider (não-trigger)Complete o PRA FAZER 1 e confira os colliders/Rigidbody.
Nenhuma caixa aparecePRA FAZER 2 incorreto, ou Caixa Prefab vazioVerifique o PRA FAZER 2 e o campo Caixa Prefab.
A caixa atravessa a esteira e caiBox Collider da esteira marcado como TriggerDesmarque Is Trigger no Box Collider do Esteira_Roletes.
Console sem mensagens de sensorPRA FAZER 3 em branco ou campo Gerenciador vazioComplete o PRA FAZER 3 e ligue o gerenciador aos sensores.
Caixas não mudam de corPRA FAZER 4 em branco ou Material Da Pintura vazioComplete o PRA FAZER 4 e confira os materiais dos cabeçotes.
Dashboard não recebe nadaServidor desligado, PRA FAZER 5/6 incompletos, ou Cliente Dashboard vazioLigue o start_dashboard.bat, complete os PRA FAZER 5 e 6 e confira as referências.
Erro "Renomeie este objeto para Sensor_…"Um sensor/cabeçote foi renomeadoVolte ao nome padrão Sensor_N / Cabecote_N.
Use o gabarito Se algo não bater, abra o projeto completo em ProjetosFinalizados/EsteiraGD_Unity no Unity Hub e compare a cena, os componentes e os valores com o seu.

18Desafios extras

  • Mudar a velocidade da esteira e as caixas por minuto e observar o efeito no dashboard.
  • Trocar as cores/texturas dos materiais de pintura.
  • Abrir o esteira.blend no Blender para evoluir o modelo 3D e reexportar o .fbx.
  • Adicionar um 5º sensor na saída para registrar a "expedição" da caixa.
